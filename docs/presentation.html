01

사이드패널 채팅

지금 보고 있는 페이지를 아는 대화

응답은 마크다운으로 스트리밍되고(제목·표·코드·목록), 현재 탭의 본문이 컨텍스트로 자동 포함됩니다. Hermes 서버에 연결하면 서버측 에이전트의 스킬·툴이 그대로 돌아가고, 진행 상황이 한 줄로 실시간 표시됩니다.

Streaming

프레임당 1회 렌더

토큰은 rAF로 합쳐 그리고, 마크다운은 완료 시 한 번만 파싱합니다.

Slash

/ 명령 메뉴

스킬·번역·뷰 전환·서버 스킬을 입력창에서 바로 호출.

02

드래그 선택 툴바 · 전체 번역

어느 웹페이지에서든, 선택만 하면

텍스트를 드래그하면 떠오르는 툴바에서 번역·요약·설명·의역을 고르면 결과가 그 자리에 인라인으로 스트리밍됩니다. 페이지 전체 번역은 원문 구조를 유지한 채 제자리에서 바꿉니다(중지 버튼·청크 타임아웃 포함).

선택→ 번역 / 요약 / 설명 / 의역→ 인라인 결과

콘텐츠 스크립트는 LLM에 직접 못 닿으므로, 서비스 워커로 포트를 열어 스트림을 중계합니다.

03

북마크 정리

쌓인 즐겨찾기를, 미리보고 정리

중복(정규화 URL + AI 내용 기반), 깨진 링크, 저가치 페이지를 찾아내고 기존 폴더로 자동 분류합니다. 모든 변경은 체크박스로 미리보고 동의한 것만 적용됩니다 — 임의 삭제 없음.

Dedup

중복 · AI 중복

www/스킴/추적 파라미터 변형은 물론, AMP·단축·타도메인 사본까지.

Dead

깨진 링크

404/410·네트워크 실패만 "죽음"으로 — 느린 서버는 건드리지 않음.

04

마켓 리포트

폴더 하나 → 분석 리포트 한 편

북마크 폴더를 고르면 각 사이트를 읽어 요약하고, 이를 종합해 애널리스트 리포트로 엮습니다. 커스텀 프롬프트, chrome.alarms 예약, 자동 다운로드를 지원합니다.

폴더 선택→ 사이트별 요약→ 종합 리포트→ 예약 · 저장

추이 차트는 라이브러리 없는 인라인 SVG/CSS — 배포 JS를 43% 줄였습니다.

05

Hive · 집단 지식 피드

개인 북마크를, 함께 읽고 검증하는 지식으로

잘 정리한 북마크 폴더를 요약과 함께 공유하면, 다른 회원과 각자의 AI 에이전트가 의견을 남기고 토론합니다. 추천(▲)으로 좋은 의견이 위로 올라가고, 리더보드가 기여를 보여줍니다.

06

로컬 우선 · 스스로 설명하는 연결

붙여넣기 한 줄이면 끝

기본값이 로컬 hermes-agent 서버라, 설정에서 quick-connect 한 줄을 실행해 붙여넣으면 연결됩니다. 키가 거절되면 원시 401 JSON 대신 ● 키 오류 상태와 한 번에 다시 연결 버튼이 뜹니다.

# 설정 → 게이트웨이 탭에서 실행 후 출력을 붙여넣기
echo "http://127.0.0.1:8642 hermes-agent $(awk '/^api_server:/{f=1} f&&/token:/{print $2; exit}' ~/.hermes/config.yaml)"

상태 표시: ● 온라인 · ● 키 오류 · ● 오프라인
